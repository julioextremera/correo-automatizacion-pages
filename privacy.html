Política de privacidad

Última actualización: 3 de octubre de 2026.

Qué es esta aplicación

"Automatización GMAIL" es una herramienta de uso estrictamente personal, desarrollada y operada por Julio Extremera para automatizar la clasificación de su propio correo de Gmail. No se ofrece como servicio a terceros ni procesa datos de ninguna otra persona.

Qué datos accede

La aplicación usa la API de Gmail con los siguientes permisos de OAuth, concedidos únicamente por su propietario sobre su propia cuenta:

  • gmail.readonly: lectura de metadatos y contenido del correo.
  • gmail.modify: aplicar etiquetas, archivar y marcar como leído.
  • gmail.send: enviar un único tipo de correo automático (un resumen diario) exclusivamente a la propia dirección del usuario.

Qué se hace con los datos

Los datos del correo (remitente, asunto, etiquetas) se procesan únicamente para decidir cómo clasificarlo, según reglas definidas por el propio usuario. El procesamiento ocurre en infraestructura de Google Cloud controlada por el propietario. No se comparte, vende ni cede ningún dato a terceros bajo ninguna circunstancia. No se usan los datos para entrenar modelos ni para publicidad.

Conservación de datos

Los metadatos de correo usados para clasificar se conservan temporalmente en almacenamiento privado del propietario (Google Cloud Storage) solo para fines de registro y poder deshacer acciones. No se conservan copias del contenido completo de los correos.
